在 Android 上玩 Minecraft Java 版

QCL-CE 是 Quanta Craft Launcher 的社区版。内置 93 个插件、支持深色模式、能下载并给全部已归档远古版本打中文补丁。

主要特性

这些都是实测可用的功能，不是规划。

插件市场 网页版

控键布局、界面排版等资源型插件。网页上挑好直接下载，国内走 gh-proxy 镜像，装进启动器即用。

界面排版自定义 新

长按任意页面进编辑模式：单击切显示/隐藏、长按拖动换位置。13 个页面都支持，排版能导出成一段文本发给别人。

整合包导入 新

支持 MultiMC / Prism、Modrinth（.mrpack）、CurseForge 三种格式。Fabric 加载器的包能直接装完就能启动。

插件市场 新

应用内一键安装资源型插件（控键布局、界面排版）。每个包都校验 sha256，对不上就拒装。

93 个内置插件 可搜索

资源标签、下载镜像、模组依赖树、存档快速定位、皮肤收藏夹…… 插件页顶部可直接搜索。

深色模式 可开关

13 个语义色 + 完整的夜间配色，正文、面板、强调色、链接色都适配。内置「跟随系统 / 始终浅色 / 始终深色」开关。

主页改版 可自定义

原来挤在底部的 8 个入口收进左侧「≡ 菜单」。菜单支持自定义排版：勾选显示哪些、上下调顺序。

全部远古版本 独有

能下载全部已归档的远古版本（181 条），并给它们打中文补丁 —— 这是其他启动器都没做的。

装模组自动补前置

下载模组时会把整条依赖链都拉下来（不只一层）。已装的自动跳过，不会重复下载。

体积 229 MB

内置的运行时按需裁剪：只保留当前设备架构的 JRE 与原生库，比全量包小约 100 MB。

和原版有什么不同

QCL-CE 基于 QCL（HMCL-PE → FCL → PojavLauncher 血统），在其之上做社区版增补。

下载与安装

当前版本 v2.0.8（versionCode 20008），仅提供 arm64 包。

GitHub 直链下载 国内镜像（gh-proxy） 全部版本

文件名 QCL-CE-v2.0.8-arm64.apk。国内直连 GitHub 慢的话用 gh-proxy 镜像 —— 它只是把同一条 GitHub 直链转发一遍，下载到的文件完全一样。

  1. 先卸载官方版。QCL-CE 与官方包签名不同，不能直接覆盖安装。
  2. 建议清除应用数据。旧设置文件可能自我延续，导致一些奇怪现象。
  3. 安装 APK。点上面的按钮下载，或到 GitHub Releases 页面自己挑。
  4. 首次启动会解压运行时，约 452 MB，需要几分钟。这一步是离线解压，断网也能装。
装不上？ 先确认手机是 arm64 架构（绝大多数现代手机都是）。 如果提示签名冲突，说明官方版没卸干净 —— 到「设置 → 应用」里把 QCL 卸载后再装。
