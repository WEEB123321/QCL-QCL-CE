# QCL-CE · Quanta Craft Launcher 社区版

> 一个独立的社区分支，不是官方版本。基于 [Quanta Craft Launcher](https://github.com/ALLEN201123/Quanta-Craft-Launcher)
> 开发，按 **GNU GPL-3.0** 授权发布。

QCL-CE 是 Android 上运行《我的世界》Java 版的启动器。它在官方 QCL 的基础上重做了界面、
加入了 42 个内置工具和 19 种语言，并保留了官方版全部的核心能力
（下载全部已归档远古版本、全远古版本中文补丁）。

**官方版的 README 保留在 [`docs/README-upstream.md`](docs/README-upstream.md)**，
里面是上游项目的完整说明 —— 本项目的核心能力与它一致，本文只讲社区版多出来的部分。

---

## 与官方版的区别

| 方面 | 说明 |
|---|---|
| **包名** | `com.qcl.launcher.ce` —— 可与官方版**同时安装**，互不冲突 |
| **界面** | 左侧竖排导航（罗马数字 + 中文竖排）、编辑式主界面、液态玻璃 |
| **插件** | 42 个内置工具 |
| **多语言** | 19 种语言可切换 |
| **诊断** | 启动路标、崩溃弹窗一键分享日志、启动前检查 |

详细的逐项说明见下一节。

## 社区版新增功能

下面这些是官方版没有的。官方版原有的能力（远古版本下载、全远古版本中文、ModLoader / Babric、
Pojav 启动后端等）全部保留，说明见 [`docs/README-upstream.md`](docs/README-upstream.md)。

### 界面

**左侧竖排导航**。官方版是底部横排 5 个 Tab，社区版改到左侧竖排：每个条目是罗马数字加中文竖排，
侧栏顶部有方形品牌印记，底部显示当前版本号。子页面也保持常驻，不会因为切页而消失。

**编辑式主界面**。页眉分三栏（`LAUNCHER — MMXXVI` / `A Journal of Play` / `EST. 2019`），
主内容区左边是当前档案区块（编号、标题、元数据、线段式轮播指示器），右边是最近游玩列表。
底部是启动按钮加页码。

**液态玻璃**。导航栏与返回栏使用 AGSL 着色器实现真折射：边缘畸变、色散（彩虹分离）、
菲涅尔边缘光。**不支持 AGSL 的设备会自动走降级路径** —— 用位图矩阵做真实的光学放大，
所以任何机器上都能看到透镜效果，不会出现「只有反光没有畸变」的半成品状态。

**账号头像**。官方版主界面中间是 3D 人物模型（SurfaceView 独立图层，会盖住同级控件），
社区版改成头像。尺寸按屏幕高度自适应（屏幕高度乘 18%，夹在 56 到 120 dp 之间），
每次回到主界面重新计算，横竖屏切换、分屏、折叠屏都能跟上。

**其他界面改动**：主色改为铁锈红；主界面图标换成独立图标库；支持背景图轮播；
加了两个轻量动效（头像浮动、按钮按下缩放），刻意不加更多以免卡顿；
启动按钮改为自适应宽度，页码靠右。

### 42 个内置插件

入口在底部导航的「插件」页，按分类分组。

- **实例管理**（9）：图标生成器、配置差异对比、健康评分、启动历史、导入向导、启动画面、启动队列、性能基准、主题编辑器
- **模组管理**（6）：标签自动分类、锁定列表、依赖树、降级工具、更新预检、更新日志聚合
- **资源**（4）：资源包合并、资源包预览图、光影兼容检测、光影预设管理
- **下载**（3）：源测速、失败自动换源、组合模板
- **存档**（5）：版本转换提醒、玩家列表、地图预览、编辑警告、游戏规则预设
- **安全与备份**（5）：文件完整性校验、密码保险箱、操作日志、服务器白名单、数据迁移
- **Java**（2）：自动匹配、参数预设
- **工具**（8）：批量重命名、服务器延迟预检、本地化词库、教程库、一键开服向导、本地百科、快速笔记、一键恢复出厂

设计上有一条硬规矩：**每个插件里做不到的部分都写在界面上**，不放点了没反应的按钮。
比如密码保险箱会明确写着「存在应用私有目录，不是加密存储」，
存档地图预览会写着「画的是已生成区块，不画地形」，
性能基准会写着「没有帧率数据源」，一键开服向导会写着「手机上开服性能很差，更适合生成配置给电脑用」。

### 多语言

19 种语言可切换：跟随系统、简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、
Español、Italiano、Русский、العربية、ไทย、Tiếng Việt、Bahasa Indonesia、Türkçe、Polski、
Português (Brasil)、Српски。

入口在插件页的语言项，切换后立即生效，不需要重启启动器。阿拉伯语会自动切换为从右到左排版。

覆盖范围是**用户最常看到的 60 条核心字符串**（主界面、常用动作、设置分类）加上 42 个插件名。
其余字符串由 Android 的资源回退机制显示英文 —— 这是部分本地化，不是全量翻译。

### 诊断与排障

- **启动路标**：启动全程埋点，日志同时写到应用私有目录、`/sdcard/QCL/` 和
  `Android/media/<包名>/`（无需权限，分区存储下唯一对外可见的位置）
- **崩溃弹窗一键分享日志**：崩溃后重开启动器会弹提示，主按钮直接走系统分享面板，
  不用自己去翻目录
- **启动前检查**：点启动时先跑一遍轻量检查（Java 运行时、内存分配、版本文件、模组数量），
  只在查出问题时才弹面板；检查本身出错绝不拦启动
- **日志中心**：实时抓取本应用日志，可按级别过滤、关键词高亮、复制、分享
- **诊断向导**：逐项自检运行环境、内存、当前实例、模组、上次启动，红点就是问题
- **安全模式**：上次启动没走完时，本次跳过原生库加载，用来判断是不是崩在加载这两个库

### 实例与存档

- **实例快照对比**：列出「某份备份到当前实例」的逐文件差异
- **占用空间分析**：按模组、存档、资源包、光影、配置、日志拆开统计；
  清理只碰日志、崩溃报告和下载残留，模组与存档一律不动
- **实例间搬运**：把模组、存档、资源包、光影、配置从一个实例搬到另一个，
  执行前先列出会覆盖谁、哪几个有兼容性问题；存档默认不勾选，因为覆盖不可逆
- **快速启动面板**：长按实例行弹出和右上角菜单相同的内容
- **存档自动备份**：每次退出游戏后备份所有存档，可设保留份数；默认关闭，因为存档可能几百 MB
- **世界信息面板**：读存档自己的 `level.dat`，展示种子、游戏版本、上次游玩、游戏模式、
  难度、极限模式、是否允许作弊、目录占用
- **种子与存档分享**：复制种子时附带版本信息；存档可打包成 zip 走系统分享

### 下载

- **下载限速**：不限速或 256K / 512K / 1M / 2M / 5M，改完立刻生效
- **暂停、继续、重试**：用 HTTP Range 续传，不是重新下载
- **仅 Wi-Fi 下载**：按网络是否计费判定，判定失败时放行而不是拦住
- **通知栏进度**：前台服务显示进度，切后台不断
- **分享菜单接入**：从微信、QQ 或文件管理器把 zip、mrpack、图片分享给启动器，
  它会问你要放哪儿（设为背景、放进资源包、放进光影、存为整合包）

### 自动化与统计

- **定时任务**：每天、每周或每月定时备份，在每次打开启动器时检查是否到期，不后台常驻
- **启动与退出脚本**：填一段 shell，工作目录是实例目录，有 60 秒超时保护
- **本地统计**：总游戏时长、启动次数、崩溃次数、各实例启动次数、最近会话
- **桌面小部件与快捷方式**：小部件显示当前实例、游戏时长、备份份数，
  点最下面那行直接启动；快捷方式认准一个实例，不同实例互不覆盖
- **快速切换账号**：长按主界面账号按钮弹出已保存账号列表，点一下即切

### 主题与外观

- **主题方案**：默认、深色、纯黑（AMOLED）三个一键预设，可导出成一行文本分享，也可导入套用
- **安全区避让**：自动检测系统栏高度、刘海挖孔安全区和大圆角半径，
  取最大值作为避让量；圆角小、没刘海的机型保持原来的满屏观感
- **兼容性数据库**：本机可编辑的「某版本加某加载器等于能用还是有坑」清单，
  内置若干条公认常识，可自建、可导出导入 JSON

## 构建

需要 JDK 17、Android SDK（compileSdk 34）与 NDK。

```bash
./gradlew :QCL:assembleDebug -Darch=arm64
```

产物在 `QCL/build/outputs/apk/debug/`。

签名配置写在 `QCL/build.gradle` 里（引用 `../qcl.keystore`）。
**签名密钥不入库** —— 自己构建的话请生成自己的密钥并改掉引用。
